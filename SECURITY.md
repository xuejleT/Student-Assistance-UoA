# Security and privacy

**Does the skill upload course material?** The project provides a workflow and local Python helpers. It does not operate a server, include telemetry, or automatically upload course material to the repository, its maintainers, or a separate project service. When you ask Codex to read or explain a document, the relevant page text, file contents, or screenshots may be processed by the Codex host and model. What is processed or retained depends on the host, account plan, settings, and tools in use. Keep restricted materials in the university-approved environment and share only what you are permitted to share. [OpenAI data-use policy](https://openai.com/policies/how-your-data-is-used-to-improve-model-performance/)

**How is student privacy handled?** For live tasks, the skill uses the browser's authenticated session or asks you to sign in on the official site. Passwords, MFA codes, cookies, personal calendar feeds, signed delivery links, grades, and transcripts belong outside public examples, commits, and issue reports. Personal exports and any preferences you ask to keep should stay in a private workspace. The published examples use fictional records. The planner rejects common access-bearing URL parameters and known personal Canvas calendar-feed URLs, but cannot identify every kind of sensitive data.

**Does it use third-party APIs?** The supplied Python helpers read local inputs and do not make network requests. The skill ships no third-party API client or API-key configuration. Live tasks use the browser tools provided by Codex to reach the university and its service providers, including Canvas and the Library catalogue. If you ask to write to an external calendar or use another connector, its provider processes the data sent for that action. GitHub hosts the source code and synthetic examples.

Check the course's AI and assessment rules before using the skill on course questions. Course authorization and your request govern actions such as starting an attempt, checking a graded answer, submitting work, changing enrolment, or writing to a calendar. [University of Auckland AI guidance](https://www.auckland.ac.nz/en/students/forms-policies-and-guidelines/student-policies-and-guidelines/academic-integrity-copyright/advice-for-student-on-using-ai.html)

For security reports, use GitHub's private vulnerability reporting when it is available. For general issues, include only synthetic steps and redacted details. If a credential or access link has already been exposed, revoke or rotate it with the issuing service before sharing a report.
